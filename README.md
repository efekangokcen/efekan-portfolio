# Ali Efekan Gökcen — Kişisel Site

Denizli'de yapay zekâ destekli web sitesi, web tasarım ve özel yazılım hizmetleri sunan kişisel tanıtım sitem. Tek sayfalık, bağımlılıksız statik HTML.

Canlı: **https://sportssimulation.net**

## İçerik

- Hizmetler ve çalışma şeklim
- Tamamlanan canlı projeler
- Teknik yetkinlikler ve kullanılan araçlar
- Sık sorulan sorular ve teklif formu (WhatsApp)

## Yapı

| Dosya | Açıklama |
|---|---|
| `index.html` | Sitenin tamamı: içerik, stil ve küçük bir JavaScript |
| `CNAME` | GitHub Pages özel alan adı |
| `robots.txt`, `sitemap.xml` | Arama motoru dosyaları |

## Yayınlama

GitHub Pages üzerinden `main` dalından yayınlanır. Değişiklik için `index.html` dosyasını düzenleyip push etmek yeterli.
